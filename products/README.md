# Product integration layer

Products consume Factory contracts; they do not redefine kernel semantics.

Planned adapters:
- `bitminer/` — mining intelligence and fleet domain logic
- `secureos/` — security telemetry, trust and enforcement domain logic
- `venture_radar/` — market signals, opportunity discovery and validation
- `archos/` — world-model, spatial intelligence and experience domain logic

Original repositories remain the source lineage. These directories are integration boundaries, not blind copies.
